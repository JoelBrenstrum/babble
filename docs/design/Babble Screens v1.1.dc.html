Screens v1.1 · remaining phone flows and web
Built with the v1 Sage tokens and components, unchanged. Each screen is shown in light then dark. New components are added to the design system sheet.
Desktop, 1280px and up
A 268px sidebar holds the wordmark, baby switcher, running-session card, nav and online caregivers. Pages use two columns: trackers next to the timeline, and list next to detail. Adding an entry opens a dialog instead of a new page. The sidebar card is hidden on Home, where the full card already shows. In Settings the running timer is shown as a top bar instead, so you can compare both treatments.
Tablet, 768–1279px
The sidebar shrinks to an 84px icon rail. The running session becomes a pulsing chip with its side and time. Two-column pages split 1fr / 1fr. The settings section list becomes a select above the form. The week table scrolls sideways.
Phone and PWA, under 768px
The rail becomes the bottom tab bar (Home, Timeline, Stats, Settings), and categories open from the Home rows. Detail panels become full screens and dialogs become bottom sheets. Layouts match the native app exactly, so the phone screens below serve both Expo and the PWA.
