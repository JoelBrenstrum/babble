Chair mode
A full-screen page for a Raspberry Pi touchscreen beside the feeding chair. It stays on, is tapped one-handed in the dark and is read from about 1 m away. There's no navigation and no scrolling. Every target is at least 88px, and actions save on one tap with a 5-second Undo instead of confirm dialogs. The only motion is the live timer and the running pulse. Each state is shown at 800×480 (Touch Display 1) and 1280×720 (Touch Display 2), dark first. Sizes scale with the shorter screen edge, so the same layout fits both displays and a portrait mount.
Night dim uses darker, less saturated versions of the dark tokens, with no new hues. The first tap while dimmed only wakes the screen for 30 seconds.
